# میز ارز

یک داشبورد قیمت لحظه‌ای ارز و ارز دیجیتال با مبدل به تومان و ریال، حالت شب/روز و پس‌زمینه‌ی مشکی با ظاهر الکترونیکی.

ساخته شده تفننی توسط دکتر فرهان گلی

## امکانات

- نمایش قیمت ۸ ارز دیجیتال و ۸ ارز خارجی به تومان
- مبدل دوطرفه بین هر دو دارایی (تومان، ریال، ارزها و کریپتوها)
- نوار تیکر متحرک بالای صفحه
- نمودار کوچک و درصد تغییر روی هر کارت، با فلش سبز/قرمز موقع تغییر قیمت
- پرچم کشورها کنار ارزهای خارجی
- ساعت تهران، جست‌وجوی سریع و تغییر حالت شب/روز
- راست‌چین و فارسی (`lang="fa"` و `dir="rtl"`)

## ساختار فایل‌ها

```
arz-live/
├── index.html   ساختار صفحه
├── style.css    ظاهر سایت (رنگ‌ها، بوردرها، پس‌زمینه، انیمیشن‌ها)
└── script.js    منطق سایت (دریافت قیمت‌ها، مبدل، جست‌وجو، دکمه‌ی شب/روز)
```

هر سه فایل باید کنار هم و با همین اسم‌ها باشند، چون `index.html` با مسیر نسبی به دو فایل دیگر وصل شده.

## اجرا

نیازی به نصب چیزی نیست. پوشه را دانلود کن و `index.html` را با مرورگر باز کن.

فونت‌ها (Vazirmatn و JetBrains Mono) از Google Fonts لود می‌شوند. بدون اینترنت از فونت پیش‌فرض سیستم استفاده می‌شود.

## منبع قیمت‌ها

قیمت‌ها هر ۱۰ ثانیه از منابع زیر گرفته می‌شوند. هر منبع که در دسترس نباشد، منبع بعدی امتحان می‌شود.

| بخش | منبع اصلی | پشتیبان |
|---|---|---|
| دلار و ارزهای بازار ایران | TGJU | قیمت تتر در نوبیتکس و والکس |
| ارز دیجیتال | CoinGecko | CryptoCompare، Binance |
| نرخ جهانی ارزها | open.er-api.com (به‌روزرسانی روزانه) | |

نوار بالای مبدل نشان می‌دهد هر بخش زنده (🟢) است یا شبیه‌سازی (🟡 و 🔴).

اگر هیچ منبعی وصل نشود، قیمت‌ها با شبیه‌سازی از آخرین عددهای شناخته‌شده ادامه پیدا می‌کنند. این حالت فقط نمایشی است.

### محدودیت‌ها

- منبع TGJU و نوبیتکس برای درخواست مستقیم از مرورگر ممکن است محدودیت CORS داشته باشند. در این صورت سایت از منبع بعدی استفاده می‌کند.
- در ایران ممکن است CoinGecko و Binance بدون VPN باز نشوند.
- دلار نوبیتکس بر پایه‌ی قیمت تتر است و دقیقاً برابر دلار بازار آزاد نیست.
- این پروژه برای تصمیم‌های مالی مناسب نیست. از منابع رسمی بازار استفاده کن.

## شخصی‌سازی

**تغییر قیمت‌های اولیه:** در `script.js` آرایه‌های `forex` و `crypto` را پیدا کن. `price` برای ارزهای خارجی به تومان و `priceUsd` برای کریپتو به دلار است. این عددها فقط وقتی استفاده می‌شوند که منابع زنده در دسترس نباشند.

**اضافه کردن ارز یا کریپتو:** یک آیتم جدید به همان آرایه‌ها اضافه کن. برای کریپتو، شناسه‌ی CoinGecko را هم به `cgIds` بده.

**تغییر زمان به‌روزرسانی:** انتهای `script.js`، مقدار `setInterval` برای `fetchUsdToman` و `fetchCrypto` (به میلی‌ثانیه). عدد خیلی کم باعث محدود شدن توسط CoinGecko می‌شود.

**تغییر رنگ‌ها:** بالای `style.css`، متغیرهای `:root[data-theme="dark"]` و `:root[data-theme="light"]`.

## نکته‌ی فنی

حالت شب/روز با صفت `data-theme` روی تگ `<html>` کنترل می‌شود، چون متغیرهای رنگ روی `:root` تعریف شده‌اند. اگر آن را روی `<body>` بگذاری رنگ‌ها اعمال نمی‌شوند.
